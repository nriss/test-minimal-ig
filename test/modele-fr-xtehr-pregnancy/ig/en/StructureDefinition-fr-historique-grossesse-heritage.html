Logical Model: Historique de grossesse (FR) - héritage réel avec tentative de renommage

Official URL: https://interop.esante.gouv.fr/ig/fhir/test-minimal/StructureDefinition/fr-historique-grossesse-heritage Version: 0.1.0
Draft as of 2026-10-19 Computable Name: HistoriqueGrossesseHeritageFR

Test d'héritage FHIR réel du modèle Xt-EHR EHDSPregnancyHistory, avec tentative de faire apparaître un nom français dans la colonne Name via alias/label sur les éléments hérités.
